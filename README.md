A university is developing a E-Learning and Course Management System using 
Kanban methodology. Create and configure a Jira Kanban project and board, define 
any 10 functional requirements as Epics, create and prioritize 10 work items with 
suitable story points, and organize 5 development activities with 5 subtasks. Manage 
work items across the Kanban board columns, review pending work and work in 
progress, and generate suitable reports to analyze project progress and status. 
Integrate GitHub by creating a repository named e-learning-course-management
demo, connecting it to Jira, creating a branch linked to a Jira work item.  
Using the E-Learning and Course Management System Kanban project, write and 
execute suitable JQL queries for the following: 
a) Display all unresolved defects with High or Highest priority. 
b) Display all issues that are assigned to the current user and are not completed. 
c) Display all issues belonging to the Course Enrolment and Registration functional 
area, excluding completed issues. 
d) Display all issues that are either of High priority or currently in the In Progress 
status. 
e) Display all high-priority issues created during the last 15 days and that are not 
completed. 
f)  Display all issues that have no assignee and are not completed. 
g) Display all issues of type Story that belong to the current project and are not 
completed. 
h)  Display all issues that are currently in the Testing status and have Medium priority. 
i)  Display all issues that were created before the last 30 days and are still unresolved. 
j)  
Display all issues that are assigned to a user and have been updated during the last 
7 days.
